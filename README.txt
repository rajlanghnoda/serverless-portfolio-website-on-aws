# Serverless Portfolio Website on AWS

## Project Overview
A personal portfolio website deployed using AWS serverless and cloud services.

## Technologies Used
- HTML
- CSS
- JavaScript
- Amazon S3
- Amazon CloudFront
- AWS Lambda
- Amazon DynamoDB

## Architecture
- Amazon S3 stores the website files.
- Amazon CloudFront delivers the website over HTTPS.
- AWS Lambda processes contact form submissions.
- Amazon DynamoDB stores contact messages.

## Project Structure
- `index.html`: Main webpage
- `style.css`: Website styling
- `script.js`: Website interactions and contact form request
- `img/`: Website images
- `screenshots/`: Project screenshots
